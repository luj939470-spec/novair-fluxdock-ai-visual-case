# Visual Strategy

## 用户与场景

| 用户 | 场景 | 痛点 | 设计机会 |
|---|---|---|---|
| 手游用户 | 长时间握持与高负载游戏 | 手机发热、握持不舒适、注意力被打断 | 让产品变成轻量的专注配件 |
| 海外年轻消费者 | 通勤、咖啡店、社交内容 | 配件过于笨重，桌面风格不统一 | 轻薄、克制、可融入日常 |
| 移动办公人群 | 视频会议、导航、桌面工作 | 手机和桌面配件缺少秩序 | 通过磁吸与简洁结构传达可控感 |

## 卖点表达

- Magnetic fit：用画面表达贴合关系，不使用未经验证的吸力数字。
- Pocket-ready form：强调轻薄与随身感，不宣称具体厚度或重量。
- Quiet focus：表达专注氛围，不宣称具体分贝。
- One clean setup.：通过桌面构图传达整洁和低干扰。

## 三种方向

### 01 / 科技冷感

- 色彩：#0A0D12 / #C6D0DA / #76B9FF
- 字体：Space Grotesk + IBM Plex Mono
- 灯光：窄角冷边光，硬朗金属高光
- 构图：暗底、近距离、对角线结构
- 渠道：产品发布页、硬件媒体、科技内容
- 优点：科技属性强，产品结构突出
- 风险：容易与电竞硬件同质化，浅色页面适配成本高
- 筛选结果：保留为探索方案，不做主方向

### 02 / 运动电竞

- 色彩：#101318 / #D8F35B / #42A5FF
- 字体：Sora + Space Mono
- 灯光：速度感侧光，少量霓虹反射
- 构图：倾斜透视、节奏切片、紧张动势
- 渠道：短视频封面、社交广告、游戏社区
- 优点：传播性强，能快速抓眼
- 风险：容易遮挡产品，办公场景覆盖不足
- 筛选结果：保留为社交广告备选

### 03 / 极简国际化（主方向）

- 色彩：#F3F0EA / #1E252B / #B8D8FF
- 字体：Inter + DM Mono
- 灯光：柔和自然光，轮廓边缘清晰
- 构图：大留白、低装饰、产品主导
- 渠道：海外电商、品牌官网、详情页、社交媒体
- 优点：产品轮廓稳定，适配多尺寸，信息清晰
- 风险：需要依靠裁切、材质和文案层级建立记忆点
- 筛选结果：作为主方向
